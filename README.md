# Projeto-UNIP

# Estação Meteorológica Inteligente (PD-II)

Projeto de monitoramento ambiental urbano com ESP32, MQTT, backend em Python e dashboard.

## Estrutura
- firmware/: código do ESP32 (simulado no Wokwi)
- backend/: API em Python e banco SQLite

## Como rodar o backend
pip install -r requirements.txt
python app.py
